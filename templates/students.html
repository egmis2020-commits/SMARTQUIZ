Bulk Student Registration

Create multiple student accounts at once. Enter one student per line.

Before creating accountsCheck the spelling of each name and confirm the gender and grade level. Print or download the generated login credentials and share them privately with students.

How to enter student details

  1. Type the student's complete name.
  2. Add Male or Female.
  3. Add a grade level from 7 to 12.
  4. Start each new student on a new line.
Example format
NameGenderGrade
Juan Dela CruzMale7
Maria SantosFemale7
Jose ReyesMale8
✓ Up to 200 students per batch
✓ Duplicate name + grade skipped
✓ Username conflicts handled automatically
