How to Read the Analysis

  • Difficulty %: higher values mean more learners answered the item correctly.
  • Discrimination %: positive values indicate that higher-performing learners answered the item correctly more often than lower-performing learners.
  • Upper / Lower: number of correct responses in the upper and lower 27% groups.
  • Needs Review: use the item for review rather than automatically deleting it. Check wording, content alignment, answer key, and distractors before revising.
