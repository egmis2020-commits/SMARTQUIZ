📦 1. Backup Data

Create a ZIP archive containing a consistent SQLite database snapshot, DuckDB analytics (when available), uploaded images and static assets, and the public URL marker if present.

Save the downloaded ZIP to a USB drive or another separate location.

♻️ 2. Restore Data

Choose a backup ZIP created by this system. It will be validated and staged; the live database is not replaced while students may still be using the server.

After staging: stop the server, then start the EXE again to apply the restore. Only restore a backup you trust.

🔄 3. Update Application

Upload the new Windows application file directly here. No update website, URL, or manifest is needed. The app checks the version, file size, Windows executable headers, and calculates a SHA-256 fingerprint before allowing installation.

Only upload an EXE obtained from a trusted source. The app verifies file structure and detects changes to the staged file, but the computed SHA-256 fingerprint does not independently prove who created the EXE. Make a data backup first. In-app installation is available in the packaged Windows EXE build; the LAN quiz itself remains offline-capable.

Safety reminders

  • Do not restore or update while a class is actively taking a quiz.
  • Backups include private student records and results; do not post them publicly.
  • Restoring replaces the current database and images with the contents of the selected backup.
  • Keep the teacher computer powered on and do not close the server during active quizzes.
